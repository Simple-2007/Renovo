# Запуск шлюза на компьютере с контроллером

Шлюз читает COM-порт Arduino и отправляет замеры на сайт
https://renovo.leikom.ru/. Прошивку контроллера менять не нужно — шлюз
работает с текущей `WeatherStation` как есть.

## 0. Проверить Python

Нужен Python 3.9 или новее. Проверка:

```powershell
py --version
```

* **Версия вывелась** — всё есть, идите к шагу 1.
* **`py` не распознан** — Python не установлен. Скачать с
  https://www.python.org/downloads/ и при установке обязательно поставить
  галочку **«Add python.exe to PATH»**, затем закрыть и заново открыть
  PowerShell.

## 1. Установка

Скопировать папку `gateway` на компьютер, затем:

```powershell
cd gateway
py -m pip install -r requirements.txt
copy .env.example .env
```

Здесь и далее используется `py -m pip` и `py`, а не `pip` и `python`:
на Windows отдельная команда `pip` часто отсутствует в PATH, даже когда сам
Python установлен нормально. Через `py -m` работает всегда.

## 2. Настройка

Открыть `.env` и заполнить:

```
SERIAL_PORT=COM4        # порт платы, см. шаг 3
BAUD=9600               # для прошивки WeatherStation
DEVICE_KEY=<ключ выдаст владелец проекта>
```

## 3. Найти порт платы

```powershell
py gateway.py --list
```

Выведет список портов с описанием. Плата обычно опознаётся как
`USB-SERIAL CH340` или `Arduino Uno`. Найденный порт вписать в `SERIAL_PORT`.

## 4. Проверить связь с сервером

```powershell
py gateway.py --check
```

Эта команда ничего не пишет в базу, только проверяет доступность сервера и
ключ. Ожидаемый ответ:

```
Связь с сервером есть.
  устройство:      Arduino UNO — цех (тест) (uno-01)
  датчики:         s1, s2, s3, s4, s5
  замеров в базе:  0
  последняя связь: данных ещё не было
```

Если тут ошибка — дальше идти смысла нет, проблема в ключе или в сети.

## 5. Запуск

**Монитор порта в Arduino IDE должен быть закрыт** — порт занимает одна
программа.

```powershell
py gateway.py
```

Ожидаемый лог:

```
15:31:04  INFO    Порт COM4 открыт на 9600 бод
15:31:06  INFO    Отправлена установка часов: 2026-08-13 15:31:06
15:31:07  WARNING Часы контроллера отдают '2000-01-01 00:00:00' — модуль DS3231
                 не найден или сбит. Время замеров будет ставить сервер.
15:31:07  INFO    запись 148 принята, датчиков: 5
```

**Первая запись появится не сразу — до 3 минут.** В прошивке
`MEASURE_INTERVAL` = 180000 мс, замеры делаются раз в три минуты.
Предупреждение про часы выводится один раз за запуск, а не каждый раз.

Результат виден на https://renovo.leikom.ru/ — карточки датчиков и график.

## Что делает шлюз

* Раз в 10 секунд шлёт плате `PING`. Это обязательно: прошивка выводит замеры
  в порт только пока считает, что ПК на связи, а флаг взводится именно этой
  командой. Без пинга записи уходят на SD-карту (а без карты теряются).
* Разбирает строки `DATA;<номер>;<время>;t1..t5` и отправляет их на сервер.
* Проверяет метку времени. Пока DS3231 не установлен, плата отдаёт
  `2000-01-01` — такие метки шлюз игнорирует, время ставит сервер. После
  установки модуля шлюз сам переключится на его время, менять ничего не надо.
* Значения `-99` (датчик не дал показаний) не отправляет — на сайте такая
  карточка станет серой вместо показа неверного числа.
* При обрыве сети пишет предупреждение в лог. Накопление данных на стороне ПК
  пока не реализовано.

## Если что-то не так

| Сообщение | Причина |
|---|---|
| `could not open port 'COM4': Access is denied` | Открыт монитор порта в Arduino IDE или уже запущена вторая копия шлюза |
| `Ключ устройства не принят` | Неверный `DEVICE_KEY` в `.env` |
| `Сервер недоступен` | Нет интернета или заблокирован доступ к renovo.leikom.ru |
| Порт открыт, но записей нет дольше 4 минут | Плата не отвечает. Проверить в мониторе порта (9600 бод), идут ли строки `DATA;...` — только сначала остановить шлюз |
| `Сервер отбросил сбойные датчики: s3` | Датчик s3 неисправен, остальные пишутся нормально |
| `Запись N без единого исправного датчика` | Все пять датчиков отдают -99, проверить линию питания |

Полный лог с подробностями: `py gateway.py --debug`
